The following rules must be followed when configuring server ports (on the router)

- Port 22 (Intern / Extern) with TCP into raph-server for ssh access
- Port 80 (Intern / Extern) with TCP into raph-server for HTTP access
- Port 443 (Intern / Extern) with TCP into raph-server for HTTPS access
- Port 51820 (Intern / Extern) with UDP into raph-server for WireGuard VPN access
